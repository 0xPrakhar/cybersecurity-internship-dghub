
# DG Interns Hub – Cybersecurity Internship (Week 1)

## 📌 Overview
This repository documents my Week 1 tasks and learnings during the **Cybersecurity Internship at DG Interns Hub**.  
The focus of this week was on **Networking Fundamentals**, covering both theoretical models and practical hands-on exercises.

## 🔑 Topics Covered
- OSI Model (7 layers of communication)
- TCP/IP Model (4 practical layers for internet communication)
- Key Protocols: HTTP/HTTPS, FTP, DNS, DHCP
- IP Addressing and Basic Subnetting
- Network Troubleshooting Commands: `ping`, `ipconfig`, `tracert`
- Cisco Packet Tracer Network Simulation

## 🖥️ Hands-On Practice
- Built a simple **PC → Switch → Router** topology in Cisco Packet Tracer  
- Configured IP addresses and tested connectivity  
- Verified communication with **4 packets sent, 4 received, 0% loss**

## 📚 Learnings
- Strengthened understanding of networking fundamentals  
- Gained confidence in using diagnostic commands  
- Learned how protocols and addressing form the backbone of cybersecurity  
- Applied concepts in a simulated environment using Cisco Packet Tracer  

## ✅ Conclusion
Week 1 provided a solid foundation in networking, which is essential for advancing into deeper cybersecurity topics.  
Looking forward to continuing this journey and building more practical skills in the upcoming weeks! 🔐💻
